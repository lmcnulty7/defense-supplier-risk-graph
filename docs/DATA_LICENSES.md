# Data sources, terms and what this repo redistributes

Checked 2026-11-19. This is a summary for a reader, not legal advice. Review the linked terms before publishing.

| Source | What is committed here | Terms (as found) | How this repo complies |
|---|---|---|---|
| **USAspending.gov** (U.S. Treasury): `/api/v2/bulk_download/awards/`, `/api/v2/download/transactions/` | `data/cache/usaspending*/`: DoD PSC-J prime awards, subawards and contract transactions (parquet, about 13 MB), each with its request body, pull time and SHA-256 | Federal spending data published for public use. GAO reports that Treasury added licensing information to the site in August 2019, stating the data may be used for commercial and non-commercial purposes apart from stated restrictions ([GAO-19-72](https://www.gao.gov/products/GAO-19-72)). The site's exact license text was not retrievable in this session. | Source and pull date recorded on every node and edge; no endorsement implied; a subset of public records, unmodified apart from column selection. **Before a public push, read the license note on usaspending.gov for any third-party (for example D&B) field restrictions.** |
| **SAM.gov Entity Management API v3** (GSA) | `data/cache/sam/entities.jsonl`: 67 entities (public sections `entityRegistration`, `coreData`; every record has `publicDisplayFlag = Y`; no points of contact) | [SAM.gov Terms of Use](https://sam.gov/about/terms-of-use): "You must use the public version of any API if you wish to display or disseminate the public-facing data"; sensitive and FOUO APIs may not be used to build a public view; scraping and bots are prohibited. | Pulled through the public API with a personal key, within the daily limit (no scraping). Only public-facing fields. The API key is never stored (responses carry SAM's own `REPLACE_WITH_API_KEY` placeholder). |
| **MENA country-risk feed v2** (the author's separate escalation project) | `data/feeds/mena/`: one validated feed file (schema 2.0.0, model outputs only) and its manifest | Model trained on openly licensed inputs: the [UCDP](https://ucdp.uu.se) Georeferenced Event Dataset and Candidate Events Dataset (CC BY 4.0; Sundberg & Melander 2013; Davies, Pettersson & Öberg 2026; Hegre et al. 2020) and [The GDELT Project](https://www.gdeltproject.org/). | Attribution carried in the snapshot manifest and here. The feed's `skill_status` (`beats_base_rate`) is honoured, and `p_escalation` stays context unless this project's backtest shows it helps. |
| **MENA feed v1 (retired, not included)** | Nothing. This repository's history has no v1 feed file, and the public agent-run logs keep only the last attempt per question, so no logged answer quotes v1. One v1 probability quoted in two judge reasons (`reports/judge_validation.json`) is replaced by a marked placeholder. | v1 was trained on ACLED data. ACLED's EULA (section 7.1, effective 2026-11-01) bars ML training and testing on ACLED content without written consent; the producer no longer publishes v1. | Excluded at export; see FINAL_REPORT, *Public release*. |
| Synthetic fixture | `fixtures/risk_feed_fixture.csv` | Invented values for tests; labelled synthetic everywhere | n/a |
| Claude API outputs | `logs/agent_runs/*.jsonl` (agent and judge transcripts on public data) | Anthropic API terms | Contain no secrets (checked; see FINAL_REPORT, publishing check) |
